FULL LIBRARY MANAGEMENT SYSTEM - C++

10 classes: Person, Member, Student, Teacher, Employee, Librarian, Book, IssueRecord, Fine, Library.

Features: add/list books, register/list members, issue/return books, keep issue records, record and pay fines. Records persist in books.txt, members.txt, issue_records.txt and fines.txt.

Compile in this folder:
g++ main.cpp Person.cpp Member.cpp Student.cpp Teacher.cpp Employee.cpp Librarian.cpp Book.cpp IssueRecord.cpp Fine.cpp Library.cpp -o library.exe

Run in PowerShell:
.\library.exe

Uses fixed-size arrays and pipe-separated text files for practice. Do not include the | character in entered fields.
